# Edmond North Football website

A local redesign concept built from the current Edmond North Football content archive and image library.

## Run locally

```bash
npm run preview:stable
```

Then open `http://localhost:3000`.

This serves the compiled local preview without the development hot-reload overlay. Use `npm run dev` only while actively editing source files.

## What is included

- Game-day homepage using current Edmond North photography and branding
- Complete 2026 varsity schedule with opponent logos
- Program, parent, recruiting, media, coaching, booster, sponsor, and tradition entry points
- Existing contact, registration, broadcast, and social links
- Responsive layouts for desktop, tablet, and mobile

Schedule details were taken from the live embedded calendar captured September 19, 2026. They should be checked before launch because dates and kickoff times can change.
